## 1. ADS-B 的定义、作用和应用场景

### 1.1 什么是 ADS-B
**ADS-B (Automatic Dependent Surveillance-Broadcast，广播式自动相关监视)** 是一种先进的民航监视技术：
*   **Automatic（自动）：** 飞机不需要接收地面的询问信号，就会周期性地向外发送自身的状态数据（如位置、高度、速度、航向等）。
*   **Dependent（相关）：** 监视精度和数据源依赖于飞机机载的定位系统（如 GPS/GNSS）以及飞行控制管理系统。
*   **Surveillance（监视）：** 用于向地面接收机或其他飞机提供监视信息。
*   **Broadcast（广播）：** 采用广播方式发送，任何配备了相应接收设备的实体（包括地面站、邻近飞机、甚至商业接收网络如 Flightradar24）都可以免费且无限制地接收并解析这些报文。

### 1.2 ADS-B 的作用
1.  **提高空域安全性：** 提供高精度、高频次（通常为每秒 1 次）的航空器位置更新，大幅缩减雷达监视的死角和延迟。
2.  **扩大监视范围：** 传统雷达（SSR/PSR）受视距和地势限制，而 ADS-B 接收机体积小、造价低，极易在偏远地区、多山地带以及近海部署。
3.  **支持机载协同监视：** 实现“机-机”广播，使飞机的驾驶舱中能够直观展现周围空域其他飞机的实时三维运动状态，提升飞行员的态势感知能力。
4.  **优化航路与节能减排：** 精确的监视能够支持减小飞机间的安全隔离距离，从而提高空域吞吐量，减少空中等待排队，降低碳排放。

### 1.3 应用场景
*   **空中交通管制 (ATC)：** 替代或辅助传统的二/三次监视雷达，进行高精度的区域管制与终端区管制。
*   **机场场面监视 (ADS-B Out)：** 监控跑道和滑行道上的航空器与保障车辆，防止场面入侵冲突。
*   **舱内态势感知 (ADS-B In)：** 邻近航空器互相监视，支持自由飞行与自主避撞。
*   **全球航班追踪：** 借助低轨卫星（Space-based ADS-B）实现全球无死角的航班定位。

## 2. Mode-S 监视雷达与应答机的基本概念

### 2.1 传统监视雷达的局限与 Mode-S 的引入
早期的民航二次雷达（SSR）主要工作在 **Mode A**（仅传输身份编码 4 位八进制码，即 Squawk Code）和 **Mode C**（仅传输气压高度）。这些传统模式存在以下严重缺陷：
*   **串扰与重叠（FRUIT / Garbling）：** 当多架飞机距离相近时，它们的应答信号会在时间上重叠，导致地面站无法正确解码。
*   **容量受限：** 地面站必须轮询发射询问信号，且无法针对性地区分特定航空器。

为了解决这一问题，国际民航组织（ICAO）设计并推广了 **Mode-S (Select)** 模式：
*   **选择性询问（Selective Address）：** Mode-S 应答机拥有全球唯一的 24 位 ICAO 飞机地址码。地面站可以通过这一独一无二的物理地址，有针对性地“点名”询问某一特定航空器，从而极大地减少了射频空域中的冗余应答。
*   **数据链传输功能：** Mode-S 不仅能够提供常规的应答，还支持地空、空空之间的双向数字数据链传输，不仅限于基本监视，还支持复杂的协同和防撞系统（TCAS）。

### 2.2 Mode-S 应答机分类
根据数据链能力，Mode-S 应答机主要分为：
1.  **Level 1 (Basic):** 仅能应答身份与气压高度。
2.  **Level 2 (Elementary Surveillance, ELS):** 具备选择性询问应答与基本数据传输能力。
3.  **Level 3 / 4 / 5 (Enhanced Surveillance, EHS):** 具备高速双向数据链与 Extended Squitter 广播能力，支持复杂的下行数据（DAPs）。

## 3. 1090ES 与 Extended Squitter 的含义

### 3.1 1090 MHz 传输载频
在 ADS-B 体系中，数据传输链路主要有两种标准：
1.  **1090ES (1090 MHz Extended Squitter)：** 工作在 1090 MHz 载频上，属于国际民航的主流标准，适用于商用大飞机及高空空域。
2.  **UAT (Universal Access Transceiver，通用接入收发机)：** 工作在 978 MHz，主要在美国通用航空（低空、小飞机）中普及。

### 3.2 Extended Squitter (ES，扩展自发广播)
*   **Squitter（自发广播）：** 指应答机在没有收到地面雷达询问的情况下，**主动、周期性**地向外发射射频脉冲报文的行为。
*   **Extended（扩展）：** Mode-S 短报文长度为 56 bit。而在 1090ES 中，为了承载更多的定位与物理状态信息，报文长度被**扩展至 112 bit**。这 112 bit 的报文就是 Extended Squitter (ES)，即扩展自发广播报文。
*   1090ES 报文是把 Mode-S 的 Extended Squitter 信号作为 ADS-B 物理层载体的一种实现方式。

## 4. 真实 Mode-S 长报文的 112 bit 结构

真实的 1090ES (Mode-S) 112 bit 报文结构如下表所示：

| 字段 | 位宽 (bits) | 对应比特区间 | 英文全称 & 作用解释 |
| :--- | :---: | :---: | :--- |
| **DF** | 5 | 1 - 5 | **Downlink Format (下行格式码)**：标识报文类型。DF=17 代表 1090ES 广播报文；DF=18 代表非 Mode-S 设备的 1090ES 报文。 |
| **CA** | 3 | 6 - 8 | **Capability (应答机能力码)**：标识应答机的通信等级和安装级别（如空/地状态、防撞系统级别）。 |
| **AA / ICAO** | 24 | 9 - 32 | **Address Announced (ICAO 飞机物理地址)**：24 位全球唯一的航空器硬件识别码，由国际民航组织分配。 |
| **ME** | 56 | 33 - 88 | **Message, Extended Squitter (扩展自发广播数据段)**：承载状态核心信息的数据段。包含飞机位置、气压高度、速度、呼号等。通过 ME 字段中的前 5 位（Type Code）标识其子报文类型。 |
| **PI / CRC** | 24 | 89 - 112 | **Parity / Interrogator Identity (校验与检错码)**：24 位 Mode-S CRC 校验码，或者在某些点对点模式中，通过将校验码与询问地面站 ID 进行异或（Overlay）来同时实现校验与寻址。 |

## 5. PPM 调制与 ADS-B 基带信号关系

### 5.1 脉冲位置调制 (Pulse Position Modulation, PPM)
在 1090ES 物理层上，射频信号使用幅度调制（ASK），而基带数据编码采用 **PPM 编码**：
*   在 1090ES 标准中，传输 1 bit 对应的数据位持续时间为 **$1\ \mu\text{s}$**。
*   这 $1\ \mu\text{s}$ 被等分为两个相等的子区间（每区间 $0.5\ \mu\text{s}$）：
    *   **传输 Bit '1'：** 在前半个微秒发送高电平脉冲，后半个微秒保持低电平。
    *   **传输 Bit '0'：** 在前半个微秒保持低电平，后半个微秒发送高电平脉冲。

$$\text{Bit 1} \longrightarrow \begin{array}{|c|c|} \hline \text{High } (0.5\,\mu\text{s}) & \text{Low } (0.5\,\mu\text{s}) \\ \hline \end{array}$$
$$\text{Bit 0} \longrightarrow \begin{array}{|c|c|} \hline \text{Low } (0.5\,\mu\text{s}) & \text{High } (0.5\,\mu\text{s}) \\ \hline \end{array}$$

### 5.2 为什么选用 PPM 调制
1.  **无直流分量与时钟恢复：** 每一位比特中都必然包含一次高电平到低电平（或反之）的跳变，便于接收端极其稳定地提取位同步时钟。
2.  **抗干扰性强：** 接收端主要通过判断在 $1\ \mu\text{s}$ 内脉冲的**相对能量位置**来决定是 '1' 还是 '0'，即使信号发生严重的幅度衰减，只要前沿跳变清晰，仍能正确判决。

### 5.3 信号组成
一个完整的 1090ES 脉冲流由两部分组成：
1.  **前导码 (Preamble)：** 持续时长为 $8\ \mu\text{s}$，包含 4 个特定的高电平同步脉冲。用于接收机识别出有 ADS-B 报文到达，并锁定接收起点。
2.  **数据块 (Data block)：** 包含 112 个 PPM 比特，持续 $112\ \mu\text{s}$。
3.  总持续时间为 $120\ \mu\text{s}$。

## 6. CRC 在无线通信中的检错作用

### 6.1 什么是 CRC
**CRC (Cyclic Redundancy Check，循环冗余校验)** 是一种基于多项式除法的信道检错编码技术：
*   发送端将待发送的信息码元视为多项式的系数，模2除以一个固定的**生成多项式 (Generator Polynomial)**。
*   将得到的余数作为校验位，附加在信息码元之后一同发射。
*   接收端收到后，用相同的生成多项式对整帧报文做模2除法。若余数为0，说明传输无误；否则说明传输过程中发生了误码。

### 6.2 检错性能
Mode-S CRC-24 使用的生成多项式为 $G(x) = x^{24} + x^{23} + x^{22} + x^{21} + x^{20} + x^{19} + x^{18} + x^{17} + x^{16} + x^{10} + x^3 + 1$，对应十六进制为 `0x1FFF409`。
它具有极强的数学检错屏障：
1.  能够检测出任意长度为 **24位或更短** 的突发错误（Burst Error）。
2.  能检出所有奇数个错码。
3.  对于长度大于 24 位的突发错误，漏检率仅为 $2^{-24} \approx 5.96 \times 10^{-8}$（即 99.999994% 的大误码段都能被拦截）。
4.  在空中的多径衰落和电磁噪声环境中，它是保障数据真实可靠的最后防线。

## 7. 本课程设计采用的简化内容与原因

真实的 ADS-B 协议极为复杂。为了突出主干通信链路，且适应课程设计课时要求，我们在本设计中做了如下合理简化：

### 7.1 位置 CPR 编码简化
*   **真实协议：** 真实的 ADS-B 位置（经纬度）采用 **CPR (Compact Position Reporting，紧凑位置报告)** 算法。它将全球划分为多个纬度带，利用奇数帧（Odd）和偶数帧（Even）交替发射，在接收端通过双帧解算或者结合已知参考点解算。该算法位宽利用率极高，但涉及极其繁琐的非线性数学运算与状态同步。
*   **本设计简化：** 采用**直接线性量化（Direct Linear Quantization）**。
    *   纬度在 $[-90^\circ, 90^\circ]$ 区间均匀量化为 10 bit（1024 个等级）。
    *   经度在 $[-180^\circ, 180^\circ]$ 区间均匀量化为 10 bit（1024 个等级）。
*   **简化原因：** 避免了 CPR 编解码算法带来的巨量软件开发调试开销，同时保留了信息层“浮点数 $\rightarrow$ 量化整数 $\rightarrow$ 比特流 $\rightarrow$ 反量化恢复”的核心信源量化与转换特征，更契合“通信原理”课程重点。

### 7.2 ME 数据类型多帧融合简化
*   **真实协议：** 飞机的状态是分多种报文发送的。例如：子报文 Type Code 19 用于速度，Type Code 11 用于空降位置。各状态通过不同时隙的多帧数据逐步在接收机进行融合拼装。
*   **本设计简化：** 将飞机的核心状态（包括高度、速度、航向、经纬度）合而为一，强行整合在同一个 56 bit 的简化 ME 数据块中，并通过固定 `Type Code = 19` 发送。
*   **简化原因：** 保证在一帧报文发送中，即可完成飞机全状态量的验证，降低多路状态机联调调试难度。

### 7.3 CRC Overlay 寻址简化
*   **真实协议：** 在特定的点对点三次雷达监视或协调报文中，末尾 24 bit 会与地面站询问机地址进行异或（Overlay）。
*   **本设计简化：** 1090ES 属于全广播模式，末尾 24 bit 仅作纯粹的 CRC-24 校验计算，不添加任何叠加寻址。
*   **简化原因：** 突出物理信道在噪声条件下的比特检错过程，方便成员5在接收端快速进行 CRC 解码判定，验证基带性能。
