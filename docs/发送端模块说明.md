# 发送端模块说明

## 1. 模块功能

成员 3 负责 ADS-B 发送端（基带仿真），完整数据流为：

```
虚拟飞机状态生成
  -> 调用成员 2 的 generate_adsb_frame(state)
  -> 得到 112 bit ADS-B / Mode-S 报文
  -> 添加 16 bit 前导码（完整 128 bit）
  -> PPM 调制（128 bit -> 256 samples）
  -> 输出数据文件与时域/频域图像
```

核心代码位于 `code/transmitter.py`，包含以下函数：

- `ensure_dirs()`：创建 data / figures / config / docs 等必要目录。
- `load_scenario_config(config_path)`：读取 JSON 场景配置并补全默认值。
- `generate_virtual_aircraft_state()`：生成单帧实验用虚拟飞机状态。
- `generate_aircraft_trajectory(config)`：基于物理运动模型生成多帧状态序列。
- `get_adsb_frame(state)`：调用成员 2 组帧并转换为字符串。
- `add_preamble(adsb_bits)`：在 112 bit 报文前添加 16 bit 前导码。
- `ppm_modulate(tx_bits)`：PPM 调制，输出 float32 采样。
- `generate_single_frame_transmission(state)`：单帧完整发送链路。
- `generate_multi_frame_transmission(states)`：多帧完整发送链路。
- `save_single_outputs(...)`：保存单帧输出（成员 4 接口）。
- `save_multi_outputs(...)`：保存多帧增强输出。
- `plot_waveform(...)` / `plot_spectrum(...)`：生成单帧时域波形与频谱图。
- `plot_aircraft_trajectory(states)`：绘制二维航迹图。
- `plot_altitude_speed_heading(states)`：绘制高度/速度/航向随帧变化图。
- `plot_multi_waveform(tx_samples_multi, num_frames)`：绘制多帧发送波形。
- `main()`：命令行入口（`--mode single|multi`，`--config <path>`）。

代码结构保证轨迹生成只依赖 config 字典、发送链路只依赖 states、文件输出与绘图彼此独立，便于后续接入 GUI。

本模块仅做基带仿真，不进行真实 1090 MHz 射频发射。

## 2. 与成员 2 的接口

发送端调用成员 2 的 `code/adsb_frame.py` 中的 `generate_adsb_frame(state)`。

联调中确认的关键事实（见 `code/test_interface.py`）：

- `generate_adsb_frame(state)` 返回的是 `list[int]`（0/1 的整数列表），**不是字符串**。
- 因此发送端使用成员 2 自带的 `bits_to_string()` 把 `list[int]` 转为 `"0"/"1"` 字符串，便于后续文本输出与比对。
- 转换后的 ADS-B 报文长度恒为 112 bit，内容只包含 `0` 和 `1`。
- 成员 2 的解析器 `parse_frame_fields` 可对生成报文回验 CRC 通过。

发送端**不修改成员 2 的报文结构与 CRC 规则**：`code/adsb_frame.py` 在本分支中无任何改动（见验收记录）。

## 3. 虚拟飞机状态数据

`generate_virtual_aircraft_state()` 生成一帧实验用虚拟飞机状态。为可复现，使用固定随机种子 `42`。

该状态的字段已根据成员 2 的真实接口完成适配，与任务最初推荐字段的对应关系如下：

| 任务推荐字段 | 成员 2 真实字段 | 说明 |
|---|---|---|
| `icao` "ABCDEF"（字符串） | `icao` 24-bit 整数 | 发送端将 ICAO 表示为整数 |
| `callsign` | （成员 2 不使用） | 成员 2 报文结构无 callsign 字段 |
| `altitude` | `altitude` | 英尺 ft，范围 0–102375 |
| `speed` | `speed` | 节 knots，范围 0–1023 |
| `heading` | `heading` | 角度（浮点），范围 [0, 360) |
| `latitude_q`（量化值） | `latitude` | 物理度数（浮点），范围 [-90, 90] |
| `longitude_q`（量化值） | `longitude` | 物理度数（浮点），范围 [-180, 180] |
| （无） | `type_code` | 成员 2 必需，0–31 |
| （无） | `df` / `ca` | 默认 17 / 5 |

该状态仅用于教学仿真，**不代表真实航班数据**。

## 4. 前导码添加

前导码固定为 Mode-S / ADS-B 标准 16 bit：

```
1010000101000000
```

完整发送 bit 流长度 = 16 bit 前导码 + 112 bit 报文 = **128 bit**。

`add_preamble(adsb_bits)` 会校验输入必须正好是 112 bit，并校验输出必须正好是 128 bit。

## 5. PPM 调制

PPM（脉冲位置调制）规则固定为：

```
bit 1 -> [1, 0]
bit 0 -> [0, 1]
```

128 bit 调制后得到 `128 * 2 = 256` 个采样点，数据类型为 `float32`，取值为 `0.0` 或 `1.0`。

`ppm_modulate(tx_bits)` 会校验输入必须正好是 128 bit，并校验输出采样点数必须正好是 256。

## 6. 输出文件

运行 `python code/transmitter.py --mode single` 后生成单帧接口文件：

- `data/tx_bits.txt`：完整 128 bit 发送 bit 流，用于 BER 对比。
- `data/adsb_frame_bits.txt`：112 bit ADS-B / Mode-S 报文。
- `data/tx_state.txt`：本次发送使用的虚拟飞机状态（人可读）。
- `data/tx_samples.dat`：float32 二进制基带采样文件，**恒为单帧 256 samples**，供 GNU Radio File Source 读取。
- `figures/tx_waveform.png`：发送端时域波形。
- `figures/tx_spectrum.png`：发送端频谱图。

运行 `python code/transmitter.py --mode multi --config config/aircraft_scenario.json` 后额外生成增强输出（详见第 9 节）：

- `data/tx_states.csv`：每帧状态表。
- `data/adsb_frame_bits_multi.txt`：每行一帧 112 bit 报文。
- `data/tx_bits_multi.txt`：每行一帧 128 bit 发送 bit 流。
- `data/tx_samples_multi.dat`：float32 二进制，长度为 `num_frames * 256`。
- `figures/aircraft_trajectory.png`：虚拟飞机二维航迹。
- `figures/altitude_speed_heading.png`：高度/速度/航向随帧变化。
- `figures/tx_waveform_multi.png`：多帧发送波形（前 3 帧）。

## 7. 与成员 4 的接口

成员 4（接收端）读取 `data/tx_samples.dat`，关键约定：

- 数据类型为 **float32**（不是 complex，也不是 byte）。
- 单帧长度为 **256 samples**。
- 采样值为 `0.0` 或 `1.0`。
- 在 GNU Radio 的 File Source 中，类型应选择 **float**，而不是 complex，也不是 byte。
- 基带仿真，采样率标称 2 Msps（ADS-B 1 Mbit/s，2 samples/bit）。

## 8. 验证结果

本地验证（使用 `E:\1Apps\miniconda3\envs\asdb\python.exe`）结果：

- ADS-B 报文长度 112 bit。
- 完整 bit 流长度 128 bit。
- PPM 后采样点数 256。
- `tx_samples.dat` 可用 `np.fromfile("data/tx_samples.dat", dtype=np.float32)` 正确读取，长度为 256。
- `figures/tx_waveform.png` 与 `figures/tx_spectrum.png` 均已生成。
- 前导码等于 `1010000101000000`，128 bit 流的后 112 bit 与 ADS-B 报文一致。
- PPM 映射满足 `1 -> [1, 0]`、`0 -> [0, 1]`，可无损还原原 bit 流。
- 成员 2 解析器 `parse_frame_fields` 对生成报文回验 CRC 通过。

## 9. 动态多帧发送增强

本增强版在保持原有单帧接口不变的前提下，新增基于物理运动模型的动态多帧发送能力，命令行入口为 `--mode multi --config config/aircraft_scenario.json`。

1. 本增强版引入基于速度、航向、时间间隔的虚拟飞机运动模型。配置文件 `config/aircraft_scenario.json` 给出初始位置/高度/速度/航向及其变化率（爬升率、加速度、转弯率），`generate_aircraft_trajectory(config)` 按等距时间间隔逐帧积分得到状态序列。
2. 每一帧状态均调用成员 2 `generate_adsb_frame(state)` 生成 112 bit 报文，字段使用 `icao` 整数、`latitude` / `longitude` 物理度数（不使用量化值）。
3. 每一帧均添加相同的 16 bit 前导码 `1010000101000000`，形成 128 bit 发送 bit 流。
4. 每一帧均按 PPM 规则 `1 -> [1,0]`、`0 -> [0,1]` 调制为 256 个 float32 采样点。
5. `data/tx_samples.dat` 仍然是成员 4 默认读取的单帧接口（multi 模式会用第 0 帧刷新它，保证成员 4 接口始终可用）。
6. `data/tx_samples_multi.dat` 是增强实验输出，长度为 `num_frames * 256`，用于多帧动态发送分析。
7. `aircraft_trajectory.png` 展示虚拟飞机二维航迹（x 轴 longitude、y 轴 latitude，并标注每帧 frame_index）。
8. `altitude_speed_heading.png` 展示高度、速度、航向随帧变化（三个子图）。
9. 本实验仍为基带仿真，不做真实 1090 MHz 射频发射。
10. 当前成员 2 实现（`code/adsb_frame.py`）对 ADS-B 字段做了**教学简化**：例如将 ME 字段直接按固定位宽切分量化高度/速度/航向/经纬度，这与真实 ADS-B（如 CPR 位置编码、Gilham 编码、ACAS 等多类型码）的完整编码规则不同；CRC-24 多项式与报文长度 112 bit 与 Mode-S 一致，但整体不代表完整真实航空标准编码，仅用于课程教学仿真。

### 9.1 运动模型

位置推进采用等距柱投影（flat-earth）近似：

```
EARTH_RADIUS_M = 6371000.0
KNOT_TO_MPS    = 0.514444

t            = i * frame_interval_s
altitude_ft  = initial_altitude_ft + vertical_rate_fpm / 60.0 * t
speed_kt     = initial_speed_kt    + acceleration_ktps * t
heading_deg  = (initial_heading_deg + turn_rate_dps * t) mod 360

speed_mps    = speed_kt * KNOT_TO_MPS
distance_m   = speed_mps * frame_interval_s
north_m      = distance_m * cos(heading)
east_m       = distance_m * sin(heading)
delta_lat    = north_m / EARTH_RADIUS_M
delta_lon    = east_m  / (EARTH_RADIUS_M * cos(lat))
```

各字段在每一帧被限制到协议合法范围：altitude ∈ [0, 102375] ft、speed ∈ [0, 1023] kt、heading ∈ [0, 360)、latitude ∈ [-90, 90]、longitude 做 `[-180, 180]` 环绕。

### 9.2 配置字段（config/aircraft_scenario.json）

| 字段 | 含义 |
|---|---|
| `icao` / `df` / `ca` / `type_code` | 报文层参数 |
| `num_frames` | 生成帧数 |
| `frame_interval_s` | 相邻报文时间间隔 |
| `initial_altitude_ft` / `vertical_rate_fpm` | 初始高度 / 爬升率 |
| `initial_speed_kt` / `acceleration_ktps` | 初始地速 / 加速度 |
| `initial_heading_deg` / `turn_rate_dps` | 初始航向 / 转弯率 |
| `initial_latitude_deg` / `initial_longitude_deg` | 初始经纬度 |
